# ISC2 Sertifikatları (2026 Bələdçisi)

Bu bələdçi sentyabr 2026 vəziyyətinə görə geniş istinad edilən **ISC2 portfolionu** əks etdirir; ISC2 təcrübə qaydalarını və CPE siyasətini dövri olaraq düzəldir, ona görə planlamazdan əvvəl rəsmi saytda yoxlayın. CompTIA əsasları, Cisco avadanlıq ekspertizasını sertifikatlaşdırırsa, **ISC2 təhlükəsizliyin idarəetmə-ve-menecment təbəqəsini** sertifikatlaşdırır — flagship CISSP security menecer, arxitektor və CISO-yolu rollar üçün iş elanlarına ən çox yazılan sertifikatdır və bir çox müəssisədə "senior engineer" ilə "head of" titulları arasındakı fərqdir.

## Portfolio bir baxışda

| Sertifikat                                                      | Təbəqə     | Tələb olunan təcrübə                        | Xidmət edir                                                                                                 |
| --------------------------------------------------------------- | ---------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **CC** — Certified in Cybersecurity                             | Giriş      | Yoxdur                                      | İlk təhlükəsizlik sertifikatı; ISC2-nin "One Million Certified" proqramı vasitəsilə pulsuz training+imtahan |
| **SSCP** — Systems Security Certified Practitioner              | Praktik    | 1+ domain-də 1 il                           | Kontrolları implement edən əl-çıyan adminlər/ops                                                            |
| **CISSP** — Certified Information Systems Security Professional | Rəhbərlik  | 2+ domain-də 5 il (waiver ilə 4)            | Security menecerlər, arxitektorlar, konsultantlar, CISO yolu                                                |
| **CCSP** — Certified Cloud Security Professional                | Spesialist | 5 il İT, 1 il bulud (CISSP 1-ni waive edir) | Bulud təhlükəsizliyi arxitektorları/mühəndisləri                                                            |
| **CGRC** — Governance, Risk and Compliance                      | Spesialist | Domain-də 2 il                              | GRC analitləri, avtorizasiya/assessment rolları                                                             |
| **CSSLP** — Secure Software Lifecycle                           | Spesialist | SDLC-də 4 il                                | AppSec lead-ləri, secure-development champion-ları                                                          |

## CISSP: iş titulunu dəyişən

CISSP **səkkiz domain-i** menecment dərinliyində test edir — Security & Risk Management, Asset Security, Security Architecture & Engineering, Communication & Network Security, Identity & Access Management, Security Assessment & Testing, Security Operations, Software Development Security. İmtahanın məşhur çətinliyi texniki triviya deyil; **risk-düşünən menecer** kimi cavab verməkdir: düzgün cavab nadirən ən texniki olanıdır, riski, biznes təsirini və mayanı ən yaxşı balanslaşdıran olandır.

İmtahandan əlavə iki darvaza:

1. **Təcrübə** — səkkiz domaindən ən azı ikisində ödənişli, tam-ştat işlə beş il. Dördillik dərəcə (və ya təsdiqlənmiş sert) bir ili waive edir. Daha az təcrübə ilə keçsəniz, **ISC2 Associate** olursunuz və çatmayan vaxtı altı ildə qazanırsınız — imtahan nəticəsi banka yatırılır.
2. **Endorsement** — mövcud ISC2 üzvü təcrübənizə və etikaya zəmanət verir; sonra İllik Baxım Haqqını (AMF) ödəyir və **hər 3 illik dövrə 120 CPE krediti** saxlayırsınız (SSCP/CCSP-tipli sertlər: dövrə 60).

**Hazırlıq reallığı:** təcrübəli mühəndislər üçün 3–6 ay, bir qalın kitab üzərində (rəsmi ISC2 bələdçiləri), "menecer kimi düşün" üslubunu daxilə etmək üçün 2.500+ practice sualı olan sual bankı və yeni imtahan əlavələrinin coverage-ı (AI təhlükəsizliyi, bulud, zero trust, DPO mövzular). Generalist üçün yayğın, effektli sıra: CompTIA Security+ → real təcrübə mövcud olanda CISSP — çox erkən CISSP-yə tələsmək əsasən işi yox, imtahanı öyrədir (bax: [CompTIA Certifications](/certifications/comptia-certifications)).

## CC: açıq olan pulsuz qapı

ISC2-nin "One Million Certified in Cybersecurity" təşəbbüsü giriş-səviyyəli **CC**-ni pulsuz etdi (öz-özünə işləyən training + imtahan). Karyera dəyişdirənlər üçün ən yüngül legitim ilk sertifikatdır: təhlükəsizlik prinsipləri, əsas kriptoqrafiya, şəbəkə təhlükəsizliyi, incident response əsasları. İlk ildən sonra eyni AMF/CPE öhdəlikləri daşıyır — kimsənin tələb etmədiyi sertifikatları yığmazdan əvvəl bunu bilmək lazımdır.

## SSCP vs CISSP: implement-edən vs qərar-verən

Bu cüt insanları çaşdırır. **SSCP** kontrolları _işlədən_ insanlar üçündür — sysadmin, şəbəkə admin, security admin — və yalnız bir il təcrübə tələb edir. **CISSP** onları _dizayn edən və idarə edən_ insanlar üçündür. Gündəlik işiniz konfiqurasiyadırsa, SSCP (və ya [Cisco](/certifications/cisco-certifications) / [Microsoft](/certifications/microsoft-certifications) yolları kimi vendor sertləri) uyğundur; işiniz siyasət yazmaq, auditlərə rəhbərlik etmək və risk qərarları sahibi olmaqdırsa, hədəf CISSP-dir.

## CCSP: pul verən bulud spesialisti

Bulud təhlükəsizliyi rolları hər digər təhlükəsizlik spesialistliyini keçir və CCSP onun tanınan sertifikatıdır: bulud konseptləri, arxitektura, buludda idarəetmə/risk/uyğunluq, data təhlükəsizliyi, platforma təhlükəsizliyi, əməliyyatlar, hüquqi. Uyğunluq: bulud təhlükəsizliyi daxil olmaqla İT-də beş il — və aktiv CISSP tam bir il hesab olunur, bu da CCSP-ni bulud işinə keçən CISSP sahibləri üçün natural _ikinci_ sertifikat edir (daha dərin bulud-arxitektura alternativi üçün [AWS Certifications](/certifications/aws-certifications) security yollarına baxın).

## CGRC və GRC nişası

İstiqamətiniz uyğunluq, assessment və avtorizasiya işidirsə ([Compliance Frameworks](/grc/compliance-frameworks)) dünyası, CGRC məhz onu sertifikatlaşdırır: tədarükdə təhlükəsizlik/risk, kontrol assessment, davamlı monitorinq, avtorizasiya qərarları. Nişadır amma az-tapan — GRC rolları tez-tez "CISSP və ya CGRC" yazır və az applicant hər ikisini saxlayır.

## Praktik playbook

1. **Giriş**: CC (pulsuz) _və ya_ Security+ — biri kifayətdir; hər ikisi redundandır.
2. **Praktik illər**: stack-inizə uyğun vendor sertləri + birillik işarəni keçəndə SSCP.
3. **Sıçrayış**: təcrübəniz banka yatırılanda və endorsement-a realist yolunuz olanda CISSP (ISC2-sertifikatlı keçmiş menecer qızıl referansdır — erkən qurun).
4. **Spesiallaşın**: bulud üçün CCSP, GRC üçün CGRC, AppSec üçün CSSLP — son iki iş elanınızın artıq yazdığını seçin.
5. **Bürokratiyaya büdcə ayırın**: hər il AMF + birinci gündən CPE loglama. Vaxtı keçən sertlər imtahanla yenidən qazanılmalıdır; CPE spreadsheet artıq işin bir hissəsidir.
